# 数据目录

程序运行时在这里读写三个文本文件（**不提交到仓库**，因为可能含个人隐私信息）：

| 文件 | 内容 |
|---|---|
| `病人信息.txt` | 病人记录，每行一个字段（姓名、性别、年龄、身份证、入院时间、病症、付费方式、科室、医生、电话、病床号、医嘱、家属、家属电话、药品、不良反应） |
| `医生信息.txt` | 医生记录（编号、姓名、擅长、科室） |
| `药品信息.txt` | 药品记录（名称、单价、产地、总价） |

## 说明

- 首次运行若文件不存在，程序从空链表开始，录入数据后通过「保存」功能写入本目录。
- 文件为纯文本，一行一个字段，无加密。
- 仓库只保留空目录与本文档，避免把演示数据（含虚构患者信息）提交上去。
