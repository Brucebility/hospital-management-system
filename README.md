# 医院病人管理系统（C 语言 · 课程设计）

> 三端（管理员 / 医生 / 用户）控制台医院信息管理系统：病人、医生、药品三类数据用链表管理，支持增删改查、医嘱与不良反应记录、文件持久化与登录鉴权。
> 本项目为《程序设计基础》课程设计作品（约 2100 行 C）。

## 功能

**角色与权限**

| 角色 | 默认账号 / 密码 | 权限 |
|---|---|---|
| 管理员 | `admin` / `12345` | 病人的增删改查、医生管理、药品管理、数据保存 |
| 医生 | `doctor` / `12345` | 查看病人（按身份证/病床/科室）、录入与修改药品、添加与修改医嘱、查看不良反应 |
| 用户（病人） | `user` / `12345` | 查看个人信息、医生、药品、医嘱，提交不良反应反馈 |

> 三种角色均支持登录后修改密码（修改只作用于本次运行，不写盘）。

**核心操作**

- 病人：录入姓名/性别/年龄/身份证/入院时间/病症/付费方式/科室/主治医生/联系方式/医嘱/家属/药品/不良反应
- 医生：编号、姓名、科室、擅长领域
- 药品：名称、单价、产地、总价
- 数据持久化：启动时从 `data/` 读取三个文本文件，退出前保存

## 技术要点

| 要点 | 实现 |
|---|---|
| 数据结构 | 三个单链表（`pat` / `doc` / `pha`），头插法建表 |
| 持久化 | `fopen` / `fprintf` / `fscanf` 读写纯文本，一行一个字段 |
| 输入处理 | `scanf` + `clearInputBuffer` 处理换行残留 |
| 界面 | 控制台 ASCII 表格 + 逐字动画 + `system("cls")` 清屏 |
| 登录 | 三种角色固定账号，5 次错误锁定退出 |

## 编译与运行

```bash
mkdir build
gcc -O2 -Wall -o build/hospital.exe src/main.c
build\hospital.exe
```

或：

```bash
mingw32-make
mingw32-make run
```

> 必须在**项目根目录**运行，程序按相对路径读写 `data/` 下的数据文件。
> Windows 控制台若中文乱码，先执行 `chcp 65001`。

## 相比原始版本修复的问题

原课程设计代码在 GCC 下无法直接编译，本仓库做了以下修复：

1. **函数内残留的错误类型声明**：`patient* readpat(patient* head1);` 使用了不存在的类型名 `patient`（应为 `struct patient`），且该声明在函数内部无实际作用，已删除。
2. **`price` 字段类型错误**：结构体中声明为 `char price`，但读取用 `%s`（写越界）、打印用 `%d`，已统一为 `int price` 并修正对应的 `scanf` / `fprintf` 格式。
3. **`scanf` 缺少取地址符**：两处 `scanf("%d", i)` 改为 `scanf("%d", &i)`。
4. **文件读循环判断错误**：`fscanf(...) == NULL` 永远不成立，读到文件末尾会死循环并产生垃圾节点，已改为校验实际读到的字段数（`!= 16` / `!= 4`）。
5. **硬编码绝对路径**：`D:\16162\Documents\*.txt` 改为相对路径 `data/*.txt`。
6. **源码编码**：原文件为 GB18030，统一转为 UTF-8。

## 安全说明（重要）

- 三种角色的账号密码**硬编码在源码中**（`admin/12345` 等），仅用于课程演示，**不适用于任何真实场景**。
- 密码修改只作用于内存，不持久化，重启后恢复默认。
- 病人数据为纯文本明文存储，无加密、无并发控制。
- 这是课程设计阶段的实现，不做生产环境的可用性承诺。

## 环境

Windows + GCC（MinGW）或 Visual Studio。依赖 `<windows.h>`（`Sleep`、`system`），非 Windows 平台需做平台适配。
